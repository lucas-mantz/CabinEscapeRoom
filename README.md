# Cabin Escape Room

**A first-person puzzle and exploration game built in Unreal Engine 5 with C++.**

You wake up inside a remote cabin at night. Explore the rooms, examine your surroundings, find clues, and work through connected puzzles to unlock your way out.

## About the Game

Cabin Escape Room is a short, single-player escape-room experience set inside a cabin surrounded by a dark forest.

Progress comes from exploring the environment and interacting with objects such as doors, keys, and a lockbox.

Your goal is simple: **find a way to escape the cabin.**

## Features

- Atmospheric cabin setting with a nighttime forest outside
- First-person exploration
- Interactable objects and doors
- Puzzle-based progression involving keys and locked areas
- Gameplay systems implemented with Unreal Engine C++ and Blueprint integration

## Download and Play (Windows)

You **do not need Unreal Engine or Visual Studio** to play the packaged game.

1. Open the repository's [Releases](../../releases) page and choose the latest release.
2. Download **all** parts of the Windows game archive (`.7z.001`, `.7z.002`, etc.).
3. Put every part in the **same folder** on your PC.
4. Install [7-Zip](https://www.7-zip.org/) if needed.
5. Right-click the `.7z.001` file and extract it with 7-Zip. It automatically combines all the parts.
6. Open the extracted game folder and run `CabinEscapeRoom.exe`.

**Important:** Keep the extracted game files and folders together.

If a future release is provided as a single `.zip`, you can instead use Windows **Extract All**.

## How to Play

Explore the cabin, investigate your surroundings, and look for objects you can interact with.

Use clues to solve puzzles, unlock new areas, and ultimately find the exit.

**Controls:** Use the in-game interaction prompts for available actions. Standard first-person movement uses the keyboard and mouse; check the prompts for the exact interaction key.
